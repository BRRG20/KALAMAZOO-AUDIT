Get your key at console.anthropic.com, then add it to your shell config so it's always available:

Add to ~/.zshrc or ~/.bashrc to make it permanent.

🚀 Step 2 — Start the server

cd terminal-tutor npm install node server.js

🔗 Step 3 — Hook your terminal

In your working terminal (separate from the server):

source /path/to/terminal-tutor/tutor.sh
